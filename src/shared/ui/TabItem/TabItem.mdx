# TabItem

Атомарный компонент отдельной вкладки. Отображает нажимаемый контейнер с текстовой меткой. Используется как дочерний элемент компонента `TabBar`, но может применяться и самостоятельно.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| label | string | — | Текст метки вкладки |
| active | boolean | false | Активное состояние вкладки |
| disabled | boolean | false | Отключает взаимодействие с вкладкой |
| onPress | () => void | — | Колбэк, вызываемый при нажатии (только если не disabled) |
| testID | string | — | Идентификатор для тестирования |

## Состояния

- **active** — фон `colors.primary.default`, цвет текста `colors.text.inverse`, скругление `borderRadius['2xl']`
- **inactive** — прозрачный фон, цвет текста `colors.text.secondary`, скругление `borderRadius['2xl']`
- **active + disabled** — фон `colors.primary.disabled`, цвет текста `colors.text.inverse`, нажатие заблокировано
- **inactive + disabled** — прозрачный фон, цвет текста `colors.text.disabled`, нажатие заблокировано

## Использование

```tsx
import { TabItem } from '@/shared/ui';

// Активная вкладка
<TabItem label="Лента" active onPress={() => console.log('pressed')} />

// Неактивная вкладка
<TabItem label="Популярное" onPress={() => console.log('pressed')} />

// Отключённая активная вкладка
<TabItem label="Архив" active disabled />

// Отключённая неактивная вкладка
<TabItem label="Черновики" disabled />
```
